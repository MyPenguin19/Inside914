FIXES
1. Cron authorization compares encoded byte lengths before timingSafeEqual. A same-character-length
   non-ASCII header now returns 401 rather than throwing. Unauthorized requests never start work.
2. Single-booking checkout stops if saving the Stripe Customer ID fails, before creating a SetupIntent.
3. Copying artwork clears stale shared provenance/crop state, refreshes updated_at for proof freshness,
   and cleans up the new object if querying the previous artwork fails.
4. Customer uploads above the renderer's 40-megapixel limit are rejected with a useful error instead
   of being accepted and subsequently failing export. The shared limit is reused by rendering.
5. SetupIntent webhooks record completion after idempotent booking processing. Interrupted processing
   remains retryable. Sequential and concurrent duplicates retain one confirmation and one email.
6. Integration-test artwork cleanup is scoped to its fixture campaign instead of all local artwork.
