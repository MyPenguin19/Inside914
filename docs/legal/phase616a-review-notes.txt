REMAINING LIVE-COLLECTION BLOCKERS — NOT SOLVED BY THE APPLICATION PRECHECK
1. A request can arrive after the last database read but before Stripe acts. A recovery client secret already delivered to a browser can remain usable. The database collection registry currently does not serialize cancellation requests with Stripe operations. Before live release, approve and implement an in-flight collection/cancellation protocol with reconciliation, revocation of recoverable payment authorization where appropriate, and concurrency tests. This requires separate database/provider-operation authorization. Existing guards must remain in force.
2. The administrative collection preview/preparation RPC does not itself check pending cancellation requests. The added per-booking application checks prevent affected new calls, but do not establish an atomic all-campaign cancellation boundary. New approved terms must not be declared fully enforced until the preceding protocol covers this path too.
3. Resolving a request is not the same as canceling a reservation. An approved cancellation must complete the appropriate cancellation/payment-resolution operation; marking a request resolved alone must not be treated as revocation. Paid or in-flight payments require a separately approved resolution, not an automatic refund.
4. Timely acknowledged artwork changes and irreversible printer commitment need an approved operating procedure and production lock. Inside914 does not place printer orders, and the database does not currently model an irrevocable printer-order commitment. Current final-proof checks are retained, but cannot by themselves prove an external printer order's cancellation/refund eligibility.
5. New approved policy identifiers, deployment authorization, preserved-consent review, provider/webhook verification and a separately approved collection release are still required. LIVE_COLLECTION_RELEASED remains false; collection mode was not changed. No price, layout, campaign, reservation, artwork, migration or payment provider configuration was changed in production.
