# Social image fonts

Fraunces 600 and Geist 500 are the existing Inside914 brand families, bundled here only for deterministic server-side Open Graph rendering. Google Fonts supplied these unmodified TrueType files on 2026-10-25; the adjoining SIL Open Font Licenses apply. They are not additional browser font downloads. `next/font` continues managing page typography.

Sources: [Fraunces](https://fonts.google.com/specimen/Fraunces), [Geist](https://fonts.google.com/specimen/Geist), [licenses](https://github.com/google/fonts/tree/main/ofl).
